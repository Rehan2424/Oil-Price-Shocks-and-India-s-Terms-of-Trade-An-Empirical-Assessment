# Presentation

| File | What it is |
|---|---|
| [`slides.pdf`](slides.pdf) | The deck we present: 13 main slides plus the thank-you slide, and 9 backup slides for the viva |
| [`slides_with_notes.pdf`](slides_with_notes.pdf) | Each slide followed by its speaker script, for rehearsal |
| `slides.tex` | Beamer source (metropolis theme, compiles with pdfLaTeX) |
| `figures/`, `tables/` | Charts and backup tables used by the slides, generated by `src/slide_figures.py` |
| `overleaf_upload.zip` | `slides.tex` + `figures/` + `tables/`, ready to upload to Overleaf |

## Who presents what (about 15 minutes)

| Speaker | Slides | Script | Time at a calm pace |
|---|---|---|---|
| P1 | Title, March 2026 hook, question and hypotheses, offer curves for India | 462 words | ~3.5 min |
| P2 | How big should the hit be, literature and gap, data | 384 words | ~3 min |
| P3 | Method, H1 (ARDL), monthly timing | 448 words | ~3.5 min |
| P4 | H2 and exposure, H3, what it means for India | 373 words | ~3 min |

That is 1,667 words: about 13 minutes at a normal speaking pace (130 words a minute), 14 at a slow one. Keep an eye
on the clock in rehearsal and trim your own script if you run over.

The slides themselves carry no speaker labels. In `slides_with_notes.pdf`, each script starts with P1 to P4.

## Editing on Overleaf

1. Download `overleaf_upload.zip` from this folder (open it on GitHub, then click the download button).
2. On Overleaf: **New Project → Upload Project**, and pick the zip.
3. Leave the compiler on **pdfLaTeX** (Menu → Settings). Recompile, and you should get the same 23 pages.
4. For the speaker notes, uncomment `\def\withnotes{}` on line 14 of `slides.tex` and recompile.

Overleaf's free plan cannot sync with GitHub. If you change something on Overleaf, download the source
(Menu → Download → Source) and send it to whoever updates the repo, so the copy here stays the final one.

## Compiling locally

```bash
cd presentation
latexmk -pdf slides.tex
latexmk -pdf -jobname=slides_with_notes -usepretex='\def\withnotes{}' slides.tex
```

The deck needs a standard TeX Live install (the `metropolis`, `FiraSans` and `tcolorbox` packages).

## Changing a number

Don't edit numbers in the slides by hand. Every chart and table here is read from `output/tables/` and
`data/processed/`. If the analysis changes, rerun the notebooks, then `python src/slide_figures.py`, then
recompile. The numbers typed directly into slide text (for example the elasticities on the H1 slide) are
listed with their source table in `viva-notes/04_results.md`, so they are easy to check.
