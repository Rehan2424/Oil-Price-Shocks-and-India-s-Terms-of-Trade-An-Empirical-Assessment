# Lecture PDFs

Upload the course lecture PDFs here, using **Add file → Upload files** on GitHub.

**Naming:** `L01_<short-topic>.pdf`, `L02_<short-topic>.pdf`, … (for example `L07_Terms_of_Trade.pdf`).

Also upload these into `course-material/`:
- the **assignment brief / marking rubric**
- the **course syllabus**, if available

These files are course material. Keep this repository **private** while they are here.
